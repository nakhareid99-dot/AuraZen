# AuraZen - AI-Powered Meditation and Soundscapes
AuraZen is a full-stack mindfulness and relaxation web platform powered by Google Gemini 3.7 Flash. It delivers real-time generated meditation scripts, synthetic voice guidance, customizable ambient soundscapes, harmonic Solfeggio frequency tuning, visual breathwork pacing, and an AI spiritual guide named Zenith.

Core Capabilities
AI-Driven Guided Meditation: Dynamic script generation customized to user intention, focus area, and target duration.

Multi-Layered Soundscape Engine: Combines natural audio textures with Solfeggio frequencies (432Hz, 528Hz, 639Hz, 741Hz).

Visual Paced Breathwork: Real-time animated breathing guide supporting Box Breathing and relaxation cycles.

Zenith Mindfulness Assistant: Context-aware conversational agent trained for stress management and mindfulness guidance.

Mindful Journaling & Progress Analytics: Records completed sessions, tracks streaks, and stores reflection logs.

Technical Stack
Frontend: React 18, TypeScript, Tailwind CSS

Audio Engine: Web Audio API, Custom AudioSynthesizer

Backend & AI: Node.js, TypeScript, Google Gemini 3.7 Flash API

Build System: Vite

Getting Started
Prerequisites
Node.js (version 18 or higher)

Google Gemini API Key

Installation
Clone the repository:

git clone https://github.com/nakhareid99-dot/AuraZen.git
cd AuraZen
Install dependencies:

npm install
Set up environment variables:

cp .env.example .env
Run the development server:

npm run dev
